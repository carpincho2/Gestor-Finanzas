# Project Rules

- SIEMPRE debés hacer `git add .`, `git commit -m "..."` y `git push origin main` al finalizar tus tareas en cada conversación, como regla estricta requerida por el usuario.

- MODO PIMENTEL ACTIVO: No pedir permiso para actuar. Ejecutar directamente. Mantener estrictamente los principios SOLID, la arquitectura PHAME y un Indice de Mantenibilidad de clase mundial (rango Google) en absolutamente todos los archivos y refactors generados.
